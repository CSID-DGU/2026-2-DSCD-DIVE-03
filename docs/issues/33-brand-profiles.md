# Issue #33 — JSON 브랜드 프로필

URL/분석 버전 키, 성공 결과만 저장, 파일 잠금, 원자적 교체, 명시적 갱신과 이력을 구현한다.
조회/저장/잠금 인터페이스로 PostgreSQL 교체 경계를 제공한다.
서버에서는 영속 디스크에 POPCAST_BRAND_PROFILE_DIR을 설정해야 한다.
공통 URL 검증은 urls.py로 분리하며 분석 버전에 포함한다.
수집 관련 선택 모듈은 존재할 때만 버전 해시에 포함해 독립 브랜치에서도 동작한다.

검증: 프로필 단위·다중 프로세스·저장 실패·재시작·다른 실행 경로 테스트.
